Boeing 707-328
Château de Maintenon

Avion long-courrier emblématique de l'aviation commerciale, conservé aux ateliers de restauration du Musée de l'Air et de l'Espace à Dugny.

Découvrir

Les avions patrimoniaux exposés en extérieur dans les musées sont fragiles : leur structure en aluminium se corrode avec le temps. Le projet de recherche C-ADER développe de nouveaux outils pour surveiller cette corrosion et mieux conserver ces avions sur le long terme. Parmi ces outils : le jumeau numérique, une maquette 3D de l'avion enrichie de données scientifiques. Cet outil permet de partager avec le public le travail de conservation mené sur ces avions exceptionnels.

Le jumeau numérique présenté sur ce site est développé dans le cadre du projet C-ADER : Conservation d'anciens aéronefs : Diagnostic non destructif des dommages pour une protection intelligente contre la corrosion, financé par l'Agence Nationale de la Recherche (ANR) sous le numéro ANR-22-CE27-0025.
